# Investment Portfolio Management Dashboard

## A responsive web application for managing investment portfolios and tracking NAV-based fund performance.

### Live Demo

https://investment-fund-tracker.netlify.app/

### Features

- Dashboard overview
- Investor management
- Investor detail pages
- Transaction management
- Interactive charts using Recharts
- Responsive UI built with Tailwind CSS
- Client-side routing with React Router
- Data persistence using browser local storage

### Tech Stack

- React
- React Router
- Tailwind CSS
- Recharts
- Vite

### Future Improvements

- Laravel REST API integration
- MySQL database
- User authentication
- Role-based access control
- Cloud deployment

### Getting Started, Clone the repository

- git clone https://github.com/LordShehzi/investment-fund-tracker
- Install dependencies
   - npm install
- Start the development server
   - npm run dev
